Users are required to cite the AerialMetric paper when using code and benchmark in
academic publications.

## MoGe2-Aerial

MoGe2-Aerial is derived from MoGe-2.

The AerialMetric modifications and related code are released under the MIT
License. The underlying MoGe-2 code remains subject to the original MoGe
license, and the included DINOv2 components remain subject to the Apache
License 2.0.

Users are required to cite the AerialMetric paper when using MoGe2-Aerial.pt in
academic publications.

Users should also comply with the licensing terms associated with the original
MoGe-2 model and its dependencies.
